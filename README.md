# android-compose

## Step1 Payments — 카드 추가 화면

1. 화면 구성
    - `NewCardScreen` 카드 추가 화면을 구현한다.
2. 각 입력 항목별 유효성 검사를 진행한다
    - 카드 번호 입력 시 4자리마다 ` - ` 구분자가 표시되도록 한다.
    - 만료일 입력 시 `MM / YY` 형식으로 ` / ` 구분자가 표시되도록 한다.
    - 비밀번호는 마스킹 처리한다.
3. 유효성 검사 (선택)
    - 카드 소유자 이름이 30자를 초과하면 에러 메시지를 표시한다.

## Step2 Payments — 카드 목록 화면
1. `PaymentsScreen`을 구현한다.
2. 카드 추가 완료 시 목록이 갱신되어야 한다.
3. 카드 개수에 따라 UI를 다르게 노출한다.
    - 0개: `"새로운 카드를 등록해주세요"` + 추가 버튼
    - 1개: 카드 1개 + 하단 추가 버튼
    - 2개 이상: 카드 목록 + 상단바 `추가` 생성


## Step3 Payments — 페이먼츠(카드사)
1. 카드사 필수 선택
    - 카드 추가 화면 진입 시 카드사를 필수로 선택해야 한다.
2. 카드사 선택 UI
3. 카드 미리보기
    - 선택한 `BankType`에 따라 `PaymentCard` 색상·카드사 이름 변경
4. (선택) 카드사 아이콘 (`drawable`)
